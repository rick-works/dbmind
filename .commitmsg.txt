提速 + 修正导出偏移错误：页 5000 -> 50000，20 万行 28.7s -> 17.2s（11925 行/秒）

- PAGE_ROWS 5000 -> 50000：实测每次向宿主取数有约 340ms 固定开销（与行数无关），
  20 万行按 5000/页要 41 次取数 = 约 14 秒纯开销，按 50000/页只要 5 次
- 新增 DBMIND_EXPORT_PROFILE=1 耗时剖析（默认零开销）：区分取数 / 写盘。
  实测取数占 82~92%（写 4 万行只要 0.46s）—— 瓶颈明确在宿主取数这一段
- 修正 offset 推进：原来 offset += page_size，而渐进策略会在读完小页后把 page_size
  改大，于是凭空跳掉一整页（前两页各 5000 行、第三页却从 offset=55000 开始），
  整表 205106 行只导出 201106 行、limit 40000 只导出 36000 行，而且无声无息
  —— 之前把这个差异误判为「数据在导出期间被改动」，其实是算错了偏移
- 改为 offset += got（本页实际读到的行数）：现在导出 205106 == 统计 205106，
  任务自检也不再报差异

验证：
  limit 40000 -> 行 40000 == 统计 40000（改前 10000）
  整表        -> 行 205106 == 统计 205106（改前 160106）
  同会话对照  -> 22.6s / 8898 行/秒  =>  17.2s / 11925 行/秒
