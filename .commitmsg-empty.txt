新建表空状态与编辑页对齐；SQL Server 不再显示固定角色的同名 schema

1. 索引 / 字段 两个空状态统一成一张虚线卡（新建表两个页签 + 编辑页同款）
   · 之前：索引页签是"一行表头 + 一大片空白"（el-table 的默认空文案），字段页签是表格里
     一行居中小字 —— 与编辑页那张"虚线卡 + 图标 + 说明 + 按钮"完全不是一套；
   · 现在两个页签**共用同一个 .empty-card**（放在 TableForm 里，只写一遍），
     所以它们之间不可能再不一致；文案复用编辑页已有的 tdet.noIndex / noIndexHint，
     字段那边新增 tf.noFields / tf.noFieldsHint（原来那条 tf.noColumns 已无人使用，删掉）。
2. SQL Server 的 schema 清单不再列出九个固定数据库角色的同名 schema
   （db_owner / db_accessadmin / db_backupoperator / db_datareader / db_datawriter /
     db_ddladmin / db_denydatareader / db_denydatawriter / db_securityadmin）。
   它们不是给用户建表用的，列在树里就是九行永远空的噪音；dbo 保留（正常的默认 schema）。
   真机验证（localhost 的 Database_1，Windows 认证直连）：
     sys.schemas 共 13 个 → 旧查询排除 3 个（guest/sys/INFORMATION_SCHEMA）→ 返回 10 个
     （正是那九个角色 + dbo，与用户截图一致）→ 新查询返回 1 个：dbo。

验证：cargo build -p dbmind-web 通过；npm run build 通过；guard 通过
