## 更新说明

- 全新「智能问数」：用一句话查数据，五步执行过程全程可视（理解问题 → 读取表结构 → 生成查询与图表方案 → 执行查询 → 阅读结果写结论），每步展开实时分析内容、跑完自动折叠，步骤多少跟着问题走，不凑数
- 问数自带只读护栏：生成的 SQL 先过内核只读校验才执行，写语句、多语句、注释一律拒绝；图表字段必须真出现在结果列里，对不上自动降级成数据表，宁可给表不给空白
- 结论基于真实结果集撰写：计划阶段的空话不要，执行完把结果再喂一次模型写一句带数字的结论，界面上的每个数都能在明细表里逐格核对；数据概况由前端本地统计，不经过模型
- 图表本地即时切换（柱状 / 折线 / 面积 / 饼图 / 环形 / 散点 / 热力 / 漏斗 / 仪表盘 / 数据表），不重新问模型；结果一键导出 CSV（带 BOM，Excel 打开中文不乱码），SQL 可一键插入编辑器继续加工
- 支持追问与澄清：缺时间范围、口径不明时先反问不出图，回答尾部给 2~3 个自然的追问，点一下就接着查
- 关窗确认不再虚报任务数：启动时把历史执行记录误当成"正在运行"（最多报 50 个），现在只统计真在跑的任务；确认弹窗也从一坨任务名改成一目一行的可滚动清单
