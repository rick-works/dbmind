发布日期：2026-10-10
类型：功能版（新增功能与默认行为变化，升级无破坏性）

## 在线更新：不用开代理，也能把包下下来

**你可能遇到过的现象**：点「在线更新」之后进度条一直停在 0%，或者转半天最后报错，
而同一台机器上浏览器打开 GitHub 又是好的。

**为什么会这样**：程序以前是直连 `github.com` 下载安装包的。实测在国内网络里，
`api.github.com`（取版本信息）1.1 秒就通，但**下载文件的域名经常完全不通** ——
最典型的一次是 21 秒超时、一个字节都没拿到。于是就成了"浏览器能下、软件下不了"。

**这次改了什么**：

- 直连不通（或慢到不像话）时，自动改用国内镜像下载，并在进度窗里写明当前从哪个源下载。
- **下载完一定校验**：用 GitHub 官方在接口里公布的 sha256 核对完整性 —— 对不上就丢弃重下。
  镜像是能替换包内容的中间人，而这个校验值它替换不了（它来自 GitHub 自己的接口），
  所以"用镜像"与"装到的必须是官方那个包"两件事不冲突。
- 中断可续传：断网、切 WiFi、合上盖子之后，从已下载的部分接着下，并明确告诉你
  「第 2 次重试（已下载 12.3 MB，接着下）」。
- 失败不用重启软件：以前一次失败之后，每次点更新图标都弹回同一个报错页，只能关掉软件重开；
  现在失败窗里有「重试」，关掉再点图标也会正常去检查更新。
- 提示不再误导：只有真的在后台下载时才显示「查看下载进度」（以前一打开软件就显示，
  点进去却是个空进度）。
- 想自己指定下载源也可以：环境变量 `DBMIND_UPDATE_MIRRORS` 填自己信任的镜像前缀。

## 驱动管理（原「驱动下载」）

设置里那一页改叫「驱动管理」，**顶栏也加了同名入口**，点一下直达 ——
每种数据库的驱动装没装、还缺哪些、换镜像源、手动上传 jar，都在同一页里。

## 生产保护：默认开启

给数据库标了生产红标（或放进 PROD 分组）的，**一切改动数据的操作默认一律拦下**：
执行脚本、改表结构、编辑数据、导入 / 同步 / 还原；查询完全不受影响。
标了开发、测试或没标红标的库照常读写。

确实要临时改生产数据时，去「设置 → 安全与会话」把它关掉即可。

> 如果你的生产保护以前是**你自己关掉**的，升级后会被打开一次 ——
> 老版本里分不清"你关的"和"当初的默认值"，只能按安全优先处理。
> 再关掉一次就好，之后不会再被翻回来。

## 其它修复

## 安装包（全平台）

按平台与使用习惯挑一个即可 —— **每个包都自带精简 Java 运行时**，装完就能连库，不必另装 Java。

| 平台 | 文件 | 形态与适用场景 | 大小 |
|---|---|---|---|
| Windows | DBmind_1.1.0_x64-setup.exe | 安装向导（推荐） | 46.3 MB |
| Windows | DBmind_1.1.0_x64_en-US.msi | MSI 包（企业批量部署 / 静默安装） | 53.4 MB |
| Windows | dbmind-1.1.0-portable.zip | **免安装**：解压即用，不写注册表，可放 U 盘 | 63.7 MB |
| macOS（Apple 芯片） | DBmind_1.1.0_aarch64.dmg | 安装镜像：拖进「应用程序」 | 52.1 MB |
| macOS（Intel） | DBmind_1.1.0_x64.dmg | 安装镜像：拖进「应用程序」 | 53.9 MB |
| Linux（Debian / Ubuntu） | DBmind_1.1.0_amd64.deb | apt 安装，带开始菜单项 | 64.9 MB |
| Linux（通用发行版） | DBmind_1.1.0_amd64.AppImage | **免安装**：`chmod +x` 后直接运行 | 137.2 MB |

- 免安装版的用法就两步：Windows 解压后运行 `start.bat`；Linux 给 AppImage 加执行权限后直接跑。
- Windows / macOS / Linux 三个平台由同一套流程、同一份代码打出，功能完全一致。

## 首次安装与打开

三个平台都是标准安装包，**装完即可用**；只因为还没有花钱买签名证书，系统会先礼貌拦一下 ——
按下面放行即可，不影响任何功能：

- **Windows**：出现「Windows 已保护你的电脑 / 未知发布者」时，点「更多信息」→「仍要运行」。
  安装向导与 MSI 都能正常安装；免安装 zip 解压后直接运行 `start.bat`，没有这类提示。
- **macOS**：出现「无法验证开发者」时，在「访达」里**右键（或按住 Control 点击）应用 → 打开 → 再点「打开」**。
  如果见到「已损坏，无法打开」（Apple 芯片上偶尔出现），执行一次下面这行就好：
  ```
  sudo xattr -dr com.apple.quarantine /Applications/DBmind.app
  ```
  放行一次之后，以后每次都正常打开。
- **Linux**：`.deb` 双击安装即可（提示缺依赖时补一句 `sudo apt -f install`）；AppImage 先 `chmod +x` 再运行。
- 等签名证书办好，后续版本会变成"双击即开、不再有任何提示"，下载渠道和文件名都不变。
