# v1.2.6

> macOS 窗口形态这一版定稿：**红绿灯与菜单同一行**，按系统那条 28pt 标题栏的基准对齐；全屏不再有空白留白

发布日期：2026-10-11
类型：修订版（无破坏性变更，建议 macOS 用户升级）

## 三个圆点该在哪一行

这一带改了三轮，把结论写清楚，免得以后再翻：

| 试过的做法 | 结果 |
|---|---|
| 无系统标题栏（`decorations(false)`），macOS 也不画自己的按钮 | **两头都没有**：没标题栏、也关不掉（v1.2.2 之前） |
| 保留系统标题栏 | 圆点被摆在**单独一行**的标题栏里，与菜单不在同一行（用户："那三个按钮不要单独一行啊"）✗ |
| **Overlay（本版）** | 内容铺到标题栏下面，圆点**浮在顶栏上、与菜单同一行** ✓ |

Overlay 的代价是：圆点的**纵向位置由系统钉死**在标题栏那条 **28pt** 条带里（圆点中心距顶 14pt），
而底层 wry 的 `inset_traffic_lights` **只能改横向**、改不了纵向。所以本版把 **顶栏在 macOS 上的高度定成 28px** ——
我们的内容中心（`align-items: center`）也落在 14px，两边才是同一条水平线。
（40px 时中心在 20px，比圆点低 6px，看着就是"圆点飘在上边"，就是上一版那个观感。）

顺带把 28px 条带里的导航项内边距收紧了一档（6px → 3px），并让 logo 取 20px，塞进这条更矮的带子里不显挤。

## 全屏时左上角不再空一块

全屏时系统会把那三个圆点连同标题栏条带一起收走，而顶栏里给它们让位的 **84px 左内缩**还留着 ——
于是左边空一块。现在前端会订阅窗口是否全屏（新增 `desktopShell.onFullscreenChange`，
配套放开了 Tauri 的 `core:window:allow-is-fullscreen` 权限），全屏时给顶栏挂上 `.is-mac-fs`，
把那 84px 撤掉。

## 关于首次打开那个拦截窗 —— 为什么我消不掉

> 无法打开「DBmind.app」，因为 Apple 无法检查其是否包含恶意软件。

**这不是应用能绕过的**，也不是打包能改的：只要这个 App 是"从网上下载"且**没有经过 Apple 公证**，
macOS 就一定拦一次。区别只在拦成哪种样子：

- **有签名、没公证**（我们现在）→ 上面那种，只有「好」；
- **签名 + 公证都齐**（你截图里那个 DBX.app）→ 换成「…Apple 对其进行了检查，未检测到任何恶意软件」
  并带一个「**打开**」按钮。**差别就是 Apple 那张公证票据。**

要拿到它：**Apple 开发者证书（99 美元/年）+ 公证**。
打包流程**已经备好** —— 在仓库 Secrets 里配 `APPLE_CERTIFICATE` / `APPLE_CERTIFICATE_PASSWORD` /
`KEYCHAIN_PASSWORD` 自动签名，再加 `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` 自动公证，
证书到手后一行代码都不用改，弹窗立刻变成带「打开」按钮的那种。

在那之前，装的时候走这条（**不用 sudo**）：双击被拦一次 → 「系统设置 → 隐私与安全性」→
在"安全性"里点「**仍要打开**」→ 再确认一次，之后正常双击即可。

## 想「一次都不弹」？先澄清两件容易白折腾的事

1. **签名不能去掉。** Apple 芯片上所有可执行代码至少要有 ad-hoc 签名才能跑；去掉签名不是"少一个弹窗"，
   而是**根本打不开**（系统改说"已损坏"）。
2. **签名 + 公证都齐，第一次打开也还是会弹一下** —— 只是换成带「**打开**」按钮的那种
   （就是前面说的 DBX 那张截图的样子），点一下就进。macOS 对"从网上下载的 App"就是这规矩。

真正**一声不响**的前提是：这个文件**不带"从网上下载"的隔离标记**（`com.apple.quarantine`）。
而这个标记是**下载它的程序**（Chrome / Safari / 邮件客户端……）打上去的 ——
换一种方式拿到文件，系统就根本不会去检查：

**办法一：终端下载（熟手首选）** —— `curl` 不打这个标记：

```bash
# 以 1.2.6 的 Apple 芯片版为例；Intel 机器把 aarch64 换成 x64
curl -LO https://github.com/rick-works/dbmind/releases/download/v1.2.6/DBmind_1.2.6_aarch64.dmg
open DBmind_1.2.6_aarch64.dmg    # 挂载后把 App 拖进「应用程序」，双击即可，不会弹任何东西
```

**办法二：从 U 盘 / 局域网共享拷过去** —— 这些途径也不打标记。

**办法三：Homebrew**（需要一份 cask；`--no-quarantine` 会替你摘掉标记）：

```bash
brew install --cask --no-quarantine dbmind
```

三条都**不需要 sudo，也不需要证书**。浏览器下载 + 双击是最省事的路，代价就是那一次提示。
