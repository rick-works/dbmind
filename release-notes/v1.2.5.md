# v1.2.5

> macOS 的窗口交给系统管：红绿灯回到它该在的位置，全屏时不再有那片空白

发布日期：2026-10-11
类型：修订版（无破坏性变更，建议 macOS 用户升级）

## 修掉两处"看着不对"

**① 三个红绿灯的位置"飘在上边"**

窗口是"无系统标题栏 + 自己画一条顶栏"的形态，红绿灯就浮在顶栏上。而它们的纵向位置由系统
固定在标题栏那条 **28pt** 的条带里（圆点中心距顶 14pt），我们的顶栏是 **40px**（中心 20px）——
差 6px，看着就是三个圆点飘在顶上。底层的 `inset_traffic_lights` **只能改横向、改不了纵向**，
所以靠页面是修不齐的。

**② 全屏之后左上角一片空**

全屏时系统会把整条标题栏连红绿灯一起收走，而顶栏里给它们让位的那段 **84px 左内缩**还留着 ——
于是左边空一块（"全屏之后左上角很空，把菜单往左挪呗"）。

**改法：交给系统。** macOS 上直接**保留系统标题栏**（不再用 Overlay）——

- 红绿灯由系统摆在那条 28pt 条带的正中，永远不会错位；
- 全屏时条带连同那段留白一起消失，等于**免费**修好了第二个问题；
- 顶栏里那 84px 左内缩随之删除。

Windows / Linux 不变：仍旧整条系统标题栏都不要，由页面自绘窗口按钮（`.win-acts`）。

## 顺带一提：DMG 与上一版修的几处都在

- **DMG 安装页**是两个大图标（128px）+「应用程序」软链，拖一下即可安装（v1.2.3 / v1.2.4）；
- **打开不再黑屏**：打包进去的资源按平台资源根查找（macOS 在 `.app/Contents/Resources/`）；
- **自带 Java 运行时能被识别**：java 可执行名按平台取（macOS 是 `java`，不是 `java.exe`）。

## macOS 首次打开那个拦截窗，能不能不弹？

不能——**只要是从网上下载、又没有经过 Apple 公证，系统一定拦一下**。这不是应用能绕过的规则。

- 你看到的那种（只有「好」按钮）：「无法打开…因为 Apple 无法检查其是否包含恶意软件」——
  说明这个包**有签名但没公证**；
- 另一种（带「打开」按钮，如别的商业软件）：「…Apple 对其进行了检查，未检测到任何恶意软件」——
  说明签名与公证都齐了。**差别就在 Apple 那张公证票据。**

**现在这样装（不需要 sudo）**：双击被拦一次 → 打开「系统设置 → 隐私与安全性」，
在"安全性"里点「仍要打开」→ 再确认一次。之后正常双击即可。
（`sudo xattr -dr com.apple.quarantine` 效果一样，但要管理员权限、去掉的是整个 App 的隔离标记，
能走上面那条就走上面那条。）

**要彻底免掉**：Apple 开发者证书（99 美元/年）+ 公证。流程**已经备好** ——
在仓库 Secrets 里配 `APPLE_CERTIFICATE` / `APPLE_CERTIFICATE_PASSWORD` / `KEYCHAIN_PASSWORD`
自动签名，再加 `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` 自动公证，
证书到手后一行代码都不用改。
