## 更新说明

- 「并发表数」不再显示 0：输入框直接显示实际会用的张数，按源/目标库连接能力算好 —— 嵌入式库（SQLite / H2 / Derby）1 张、Doris / Oracle / 达梦 / DB2 3 张、MySQL / MariaDB / PG / SQL Server / ClickHouse 8 张，再与已选对象数取小；想调小直接改，改了就按改的走
- 「?」里的说明同步改成「已按源/目标库的连接能力填好默认值」
- 到这一步，同步选项里三个数字都是「显示实际生效值、可直接改」：并发表数、每批行数、超时时间
