## 更新说明

- 高级搜索支持「多套条件」：组内可以选全部满足 / 任一满足，组与组之间也能选，真正拼成 (a AND b) OR (c AND d)；条件改成一行一条、列名与值框上下对齐，区间条件的起止时间在同一个范围框里连选
- 左侧树的脚本节点右键多了「查看 / 重命名 / 删除」：改名后已打开的页签标题一起改，树只刷新这个库的脚本目录（不再整棵树重载），同一库下重名会被拦下
- 数据传输选完库自动带出默认模式（SQL Server 是 dbo、PostgreSQL 是 public），库还没选时不再显示模式；任务标题写上这一趟的对象规模（· 31 表 2 视图），同名重跑的任务能一眼区分
- 深色主题下日期 / 时间选择面板不再整块发白：面板底、禁用日期、区间底色、时分秒列都换成了深色
