# v1.2.0

> 这一版只做两件事：把「驱动装不上」从你手里拿走（自动选源、失败自动换源），再把三个表格在宽表下的横向滚动与表头观感一起收拾干净

发布日期：2026-10-10
类型：功能更新（不破坏既有用法，可直接升级）

## 驱动不用再挑镜像了

- **自动选源**：以前下载驱动要选一个镜像源，选错了就卡在那里。现在默认是「自动」——
  按 **阿里云 → 华为云 → 腾讯云 → Maven 中心** 的顺序依次试；单个源 **60 秒**超时，
  连不上、或 60 秒还没把这一份下完，就自动换下一个。换源只写日志、不动界面：
  你只会看到「驱动装好了」，不需要知道中间换过源。
- **你设了就听你的**：手动指定了镜像源（阿里云 / 腾讯云 / 内网自定义仓库）时，只走你设的那一个 ——
  **绝不偷偷换源**。企业内网仓库往往是唯一通路，换到公网既不通、也不合规。
- **设置页「驱动管理」顺带修了两处**：切到该页签就会重新加载（原来只在打开设置时加载一次，
  而那一次是在面板还隐藏时跑的，列表常常是空的、得手点「刷新」才出来）；
  镜像下拉框的宽度改为按当前文字实测，不再是一个固定的宽框。

## 宽表横向滚动更跟手

- **结果表格与 NoSQL 预览也做了「列窗口化」**：数据行只渲染可视区那几列（此前只有「表数据」这么做）。
  一百多列的宽表横向拖动时，不再一次性补几百个单元格；左右用占位格撑住被回收列的宽度，
  表头与列宽拖拽热区照旧按真实列号工作。活动单元格被滚出窗口时，会自动横向滚动把它带回来。
- **结果表格滚动期间不再做悬浮判定**：列缘的命中判定要读布局，而滚动这一帧 DOM 刚改过 ——
  等于每帧一次强制布局，拖滚动条就发涩。现在滚动中跳过、停手 120ms 后补判一次：
  拖动更顺，松开后把鼠标移到列边界，列宽调整光标照常出现。

## 表头一眼可辨

- **底色与数据区拉开一档**：浅色主题的表头底原本与斑马纹几乎同色，看着就是「又一行数据」；
  现在明显更深、更偏蓝，并在表头下沿加一条 **2px 压边线**。
- **滚起来有轻微浮起感**：表头压着数据滚动时，下沿投一道很轻的影；滚回顶部就消失。
- **类型图标按类型上色**：文本 / 字符串列原来是**灰色**的（与「没上色」几乎无差别，
  而它恰恰是列数最多的一类），现在文本类是玫红，与数值蓝、日期紫、JSON 橙、布尔绿、
  键琥珀、二进制灰都拉开了色系。
- **选中列时表头不再「看穿」**：表头是吸顶的，选中填充改为不透明打底 ——
  滚动时下面的数据不会再从表头里透出来；选中浓度也加了一档，更容易看出选中了哪一列。

## 光标口径统一

- 表头、数据格、左侧资源树的节点 —— 一律**手型**。此前「表头是手、数据格是箭头」、
  「资源树里只有数据源那一行是箭头」，都是历史遗留的不一致。
- 列宽把手（贴列缘、以及列与列之间的中线）仍是**横竖箭头** —— 那是有意的，Excel / DataGrip 同款。

## 安装包（全平台）

| 平台 | 文件 | 形态与适用场景 |
|---|---|---|
| Windows | DBmind_1.2.0_x64-setup.exe | 安装向导（推荐） |
| Windows | DBmind_1.2.0_x64_en-US.msi | MSI 包（企业批量部署 / 静默安装） |
| Windows | dbmind-1.2.0-portable.zip | **免安装**：解压即用，不写注册表 |
| macOS（Apple 芯片） | DBmind_1.2.0_aarch64.dmg | 安装镜像：拖进「应用程序」 |
| macOS（Intel） | DBmind_1.2.0_x64.dmg | 安装镜像：拖进「应用程序」 |
| Linux（Debian / Ubuntu） | DBmind_1.2.0_amd64.deb | apt 安装，带开始菜单项 |
| Linux（通用发行版） | DBmind_1.2.0_amd64.AppImage | **免安装**：`chmod +x` 后直接运行 |

- 每个包都自带精简 Java 运行时（目标机器不必另装 Java）。
- 未配置签名证书：macOS 首次打开需到「隐私与安全性」放行，Windows 会提示「未知发布者」。

## 升级提示

- 无破坏性变更，覆盖安装或替换免安装包即可；连接、脚本与设置都保留。
- 驱动镜像的默认值变为「自动」。**你之前手动设过的镜像源会原样保留**，不会被改掉；
  想交给自动挑源，在「设置 → 驱动管理 → 镜像」里选「自动」即可。
