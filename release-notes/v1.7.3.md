## 更新说明

- 同一个库内的数据传输改成「服务端自己搬」：MySQL 早就有的直拷通道，现在 SQL Server / PostgreSQL / Oracle / DB2 / ClickHouse / Doris 也都有了 —— 20 万行 6 列的表，SQL Server 从 239 秒降到 6 秒
- SQL Server 跨实例同步也快了一大截（239 秒 → 35 秒）：写入的预编译批此前一直是失效状态（事务保存点建不出来就静默降级），现在改用它自己的保存点语句；中等大小的表也不再退化成单连接搬运
- 修掉 DB2「清空后导入」失败的老问题
