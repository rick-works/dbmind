## 渲染器支持什么

标题（# 到 ######）、普通段落、粗体、斜体、行内代码、无序与有序列表、
引用块、分割线、表格、代码块 —— 这些都正常渲染。

**不支持**（写了会退化成纯文本，别用）：

- 图片语法
- 原始 HTML 标签
- 任务列表（- [ ] 待办）
- 嵌套列表（缩进子项会被平铺）

## 两条约定

1. **正文别太长**：弹窗只显示开头约 320 字符，超出部分折叠成「查看完整更新说明 ->」
   链接 —— 把最重要的放最前面。
2. **校验值别写进正文**：SHA256 放成 Release 资产（SHA256SUMS.txt），
   弹窗里只放下载表格（普通用户不需要核对哈希）。
