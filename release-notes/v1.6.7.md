## 更新说明

- 表清单（对象列表）里可以直接改表注释：回车或失焦即保存、Esc 还原，双击注释格或点右侧放大图标打开多行编辑框 —— 与「编辑表结构」的字段注释同一套操作和观感
- 改注释按数据源自动选语法：MySQL / Doris / ClickHouse 走 ALTER TABLE … COMMENT / MODIFY COMMENT，SQL Server 走扩展属性，PG / Oracle / DB2 / H2 走 COMMENT ON TABLE，不会再生成对方不认的 SQL
- Redis / MongoDB / Elasticsearch 的连接对话框现在能填用户名和密码（以前这两个框是藏起来的，开了认证的实例根本连不上），留空即按无认证连接
