## DMG：两个大图标，拖一下就能装

v1.2.3 已经用 dmgbuild 换掉了「图标堆在左上角」的那种安装页，但图标尺寸当时取的是 96 —— 偏小。
这一版按 macOS 磁盘镜像的经典尺寸改成 **128**，左 `DBmind.app`、右「应用程序」软链，
中间留出拖动距离：

```
┌──────────────────────────────────────────┐
│                                          │
│      ▣ DBmind.app      →    ▤ 应用程序    │
│                                          │
└──────────────────────────────────────────┘
```

## macOS 窗口：红绿灯回来了

**症状**：窗口能开、界面也出来了，但**没有标题栏**，也不见最小化/最大化/关闭那几个按钮。

**原因**：主程序对**所有平台**都用了 `decorations(false)`（关掉系统标题栏，让页面自绘一条），
而前端的判断是「macOS 上系统会给红绿灯，页面不要再画一套」→ macOS 下自绘按钮被跳过。
两边各自的假设都成立，凑到一起就成了：系统那套被关掉、页面那套不画 —— **两头都没有**。
顺带一提，顶栏那 84px 的左边距（`.topbar.is-mac`）本来就是留给红绿灯的，等于一直在为两位不存在的按钮留位置。

**改法**：标题栏按平台分开处理 ——

- Windows / Linux：照旧 `decorations(false)`，页面自绘三个按钮（`.win-acts`）。
- macOS：改用 **Overlay**（`title_bar_style(Overlay)` + `hidden_title(true)`）——
  系统红绿灯保留、标题文字隐藏、内容铺到标题栏下面，顶栏那 84px 留白正好给红绿灯。

## macOS 首次打开会看到什么（以及为什么）

第一次打开会弹一个**只有「好」按钮**的拦截窗：

> 无法打开「DBmind.app」，因为 Apple 无法检查其是否包含恶意软件。此软件需要更新。

这**不是"有毒"**，而是 Apple 掌握的信息不完整：

- 这个包**有签名**（ad-hoc 自签名 —— Apple 芯片上没它连跑都跑不起来）；
- 但**没有公证**（notarization），也就是没让 Apple 事先扫一遍、签一张"我检查过"的票据。

两者都齐的 App 弹的是另一种：「…是从互联网下载的 App。你确定要打开它吗？Apple 对其进行了检查，
未检测到任何恶意软件」并且带一个「**打开**」按钮 —— **区别就在那张票据**。

**现在怎么装（不需要 sudo）**：

1. 双击打开，被拦一次（点「好」）；
2. 进「系统设置 → 隐私与安全性」，页面下方"安全性"里会出现刚才那次拦截，点「**仍要打开**」；
3. 再确认一次，之后就能正常双击打开了。

（命令行那条 `sudo xattr -dr com.apple.quarantine /Applications/DBmind.app` 效果相同，
但它要管理员权限、去掉的是整个 App 的隔离标记 —— 能走上面那条就走上面那条。）

**要彻底免掉这一步**，只有 Apple 开发者证书（99 美元/年）+ 公证这一条路。
打包流程**已经备好**：在仓库 Secrets 里配 `APPLE_CERTIFICATE` / `APPLE_CERTIFICATE_PASSWORD` /
`KEYCHAIN_PASSWORD` 自动签名，再加 `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` 自动公证 ——
证书到手后**一行代码都不用改**，弹窗就会变成带「打开」按钮的那种。
