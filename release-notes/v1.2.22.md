## 更新说明

- **只读 / 生产库的写操作，点击那一刻就拦下**：导入数据、数据生成、清空表、截断表、删除表 / 删除对象、重命名 —— 连接是只读、或标了生产且开着「生产库保护」时，点下去直接拦下，**连弹窗都不打开**。以前要把整个流程走完、提交那一刻才被拒（"选完文件、传完才被告知不许导"）
- **拦截提示统一在右上角，并且能直接去改**：这类提示全部走右上角通知（不再在中间再蹦一条重复的红字）；只读那条带一个「去修改数据源 →」按钮，点开就是**这个数据源**的编辑弹窗、并停在「高级 → 只读」那一项上高亮一下；生产保护那条直达「设置 → 安全与会话」。同一条通知在结构页、数据编辑、SQL 编辑器、重命名弹窗等处表现一致
- **树上悬停看表注释**：悬停表 / 视图即可看注释（原先没有入口），卡片贴在行的右侧**树外**（不被树容器裁切）、宽度按内容自适应、外观与连接悬浮卡同款（含小三角尖）
- **连接名后的角标统一了，并按主题取色**：环境（开发 / 测试 / 生产 / 预发 / UAT）与「只读」以前各写一套尺寸与字重、浓淡也不同；现在完全同一套（10px / 600 / 高 15 / 圆角 4 / 同款边框）。颜色随主题走 —— 浅色主题下这几个颜色都换成了看得清的深一档（原先「测试」的琥珀在白底上几乎看不清），深色主题保持原来的鲜艳色
- **首页与树上的一批体验修复**：查询趋势改为**按天聚合**（不再把同一天拆成多根柱子）；空表显示 **0** 而不是一片空白，并修掉大库一次性 COUNT 导致的长时间不出数（改为分批回填，三百多张表也能很快看到前几批）；删除类图标全项目统一成红色；表结构预览的两处提示合并为一条
- **一轮前后端体检**：修掉 1 处功能损坏、2 处「静默假成功 / 丢数据」、4 处串数据（不同表 / 库之间的状态互相污染），以及发版脚本的错位问题
