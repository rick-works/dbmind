## 更新说明

- 新增「并发会话上限」设置（默认 8）：同步搬数据时，取表结构、监控轮询不再排满 30 秒报「等待可用连接超时」
- 同步取源表结构遇到会话排队超时改为自动重试（1 秒 / 3 秒），不再把本来正常的表判为失败
- 同步日志的「已写 N 秒，继续等待」带上表名，多表并行时能分清是哪一张在等
