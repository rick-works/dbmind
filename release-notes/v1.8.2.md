## 更新说明

- AI 支持多轮对话：「自主排查」以前不带上下文，说「继续」只会回「上次的对话我这边没有」并重头体检一遍 —— 现在它会接着上一轮的结论往下做；一次问两张表也不再被范围提示按回一张（聚焦表和提问里点到的表取并集，问到几张展开几张）
- AI 更省 token：压缩内置提示词与工具说明、大库不再把 150 个表名塞进上下文、历史对话按条数与字数双预算裁剪 —— 实测同一问题修复 promptTokens 2345→956、对话 2404→1030；新增「这次请求花在哪」的零成本账本接口与日志
- 「试跑结果」弹窗终于能显示数据：原来字段形状对不上，查询返回几百行也恒显示「执行成功，但没有返回数据 · 0 行 · 0 ms」；会话没选定默认库时会明确说明，不再伪装成「没数据」
- 数据目录自动瘦身：开机后台回收元数据库空洞、清理过期快照与遗留临时文件（实测 805 MB → 54 MB，整个数据目录 1.5 GB → 223 MB），清空日志/缓存后当场回收
- 问「这个库是干嘛的」不再只回一句「共 395 张表」：库级问题、以及大库里没认出具体表名的提问，改成把全库清单（表名 + 表注释）当最小上下文给模型（395 张表约 2.7k tokens，整库的列结构要几十万），能直接讲清业务；同时明确要求它「要写 SQL 先问表名」，不再照着陌生表名编字段。已经递了 SQL 的修复/解释请求仍保持精简，不塞这份清单
