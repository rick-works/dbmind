## 更新说明

- 树里的对象可直接拖进 SQL 编辑器：按住表 / 视图 / 存储过程 / 函数 / 触发器拖到编辑器松手，名字即写入光标处（有选区则替换选区），省掉手敲拼错；双击仍是打开数据预览
- 存储过程右键新增「执行」：自动打开脚本页签并按方言填好调用语句（MySQL 的 CALL、SQL Server 的 EXEC、Oracle 的匿名块…），参数按名字生成 `:变量` 占位符，执行时走模板变量弹窗取值
- README 与文档的官网地址统一为 dbmind.top（GitHub Pages 旧地址已退役）
