## 更新说明

- 「增量 / 合并 / 设了每表行数上限」的同步收尾不再比较行数、也不再清空重传目标表 —— 过去一判「不一致」就先 truncate 再灌，等于替用户删掉目标端已有的历史数据
- 「传输数」改成只在一个地方记账（INSERT / upsert / 快速装载各记一次，引擎层不再重复累加）：与「读取数」同口径，不再偏高，也不再出现读取一路涨、传输恒为 0
- 同步读页按「实际拿回的行数」推进（读侧少给几行也不会跳过没读到的数据），DBMIND_SYNC_PAGE_ROWS 在链路抖动缩页后能自己爬回设定值；日志里写明「同时搬 N 张表（自动 / 界面设置）」，结果卡上的大数字也不再挤在一起
