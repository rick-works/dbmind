## 更新说明

- mac / Linux 上保存文件现在会弹系统的「另存为」面板：导出表数据、查询结果、透视表、ER 图、AI 报告、连接配置……都能自己选目录、自己改文件名，不再静默落进「下载」目录（以前只提示一句「已导出」，根本不知道文件去哪了）
- 大表 / 整库导出不再把几十 MB 的产物拉回前端内存：选完位置后由内核直接写到你选的路径
- 保存失败不再「假成功」：桌面壳里打不开另存为会明确报错，而不是悄悄退回下载目录还说导出成功；顺带修掉 AI 面板取消导出后导出按钮一直转圈
- mac 上顶栏「官网 / GitHub」两个图标比同排小一圈的问题修掉（Windows 不受影响）
