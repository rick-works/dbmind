## 更新说明

- 新建数据库参数补全：SQL Server 可选排序规则，PostgreSQL 可设编码/所有者/连接上限，MySQL/MariaDB 字符集与排序规则下拉放全并支持筛选
- 「建库语句」补全 SQL Server 的排序规则、数据/日志文件与恢复模式，普通权限登录不再显示空白
- 修复 SQL 美化后行首 SET 把「ALTER … SET …」语句切成两段、执行报语法错的问题
