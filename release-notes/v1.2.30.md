## 更新说明

- 用户管理权限矩阵全面增强：所有数据库、所有权限项的列头都带中文小字说明（含 ClickHouse 全套权限、各外部数据源、SQL Server ANY 系列），不用再猜英文权限名
- ClickHouse 用户支持表/视图级授权：新增「表权限」页签，选库选表勾权限即可生成 `GRANT … ON 库.表`；数据库权限的分组计数分母不再显示 0
- 权限列头小字从 10px 放大到 11px，更易读；动态出现的未知权限名也有兜底说明（动词 + 名词自动组词）
- MySQL 5.7 兼容：服务器是 5.7 时自动隐藏 CREATE ROLE / DROP ROLE（8.0 才有，勾上保存必报 1064 语法错）
- 修复编辑表结构 / 树展开等元数据调用在首次之后无限排队、30 秒超时的问题（内嵌 agent 的会话锁泄漏）
