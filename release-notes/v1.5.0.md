## 更新说明

- 写入更快：同步到 MySQL / MariaDB 目标改走 `LOAD DATA LOCAL INFILE` 快通道（纯插入时自动启用），服务端不再逐行解析 SQL —— 同机实测 5~8 万行/秒，多值 INSERT 是 2~3 万；服务端没开 `local_infile` 这类情况自动改回 INSERT，日志里说一句，已写的行不会重写
- 跳过目标端 binlog：勾上后写入不再为每行多写一份 binlog，写放大减半、同步更快（仅 MySQL / MariaDB 目标）；目标库有从库、或靠 binlog 做同步与审计时别勾
- 保住类型精度：结构同步不再抹平 `datetime(6)` / `time(3)` 的微秒与 `decimal` 的小数位（以前同步完微秒就没了），`bigint unsigned` 这类超过 9223372036854775807 的值不再被截成上限
- 进度更清楚：同步进度卡加「已传输对象」，和「对象总数」并排，几百张表搬到第几张一眼看得出
