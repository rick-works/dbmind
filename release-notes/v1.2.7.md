## DMG 里多了一份说明书

macOS 对"从网上下载、且没有经过 Apple 公证"的 App 一定会拦一次（这不是应用能绕过的，也不是打包能改的）。
以前被拦的那一刻，用户只能自己去网上翻怎么放行 —— 现在这份说明书**就在同一个窗口里**：

```
┌──────────────────────────────────────────────┐
│                                              │
│      ▣ DBmind.app     →     ▤ 应用程序        │
│                                              │
│           📄 首次打开请看这里.txt              │
└──────────────────────────────────────────────┘
```

里面写清了那三步（点「好」→ 系统设置 →「隐私与安全性」→「仍要打开」→ 确认），
并注明**不用 sudo、不用敲命令**。

## 一次都不弹的两条做法

弹窗的开关不是签名，而是文件上那个 **"从网上下载"的标记**（`com.apple.quarantine`）——
它是**下载它的程序**（Chrome / Safari / 邮件客户端……）打上去的。换个方式拿到文件，系统根本不会去检查：

**① 用 curl 下载**（熟手）：

```bash
curl -LO https://github.com/rick-works/dbmind/releases/download/v1.2.7/DBmind_1.2.7_aarch64.dmg
open DBmind_1.2.7_aarch64.dmg      # 挂载 → 拖进「应用程序」→ 双击，全程不弹
```

（Intel 机器把文件名里的 `aarch64` 换成 `x64`。curl 不打那个标记，所以什么都不会弹。）

**② 用 Homebrew**（新增的 cask，`--no-quarantine` 会替你摘掉标记）：

```bash
brew install --cask --no-quarantine rick-works/tap/dbmind
```

两条都**不需要 sudo、不需要证书**。

## 顺带说清两件容易白折腾的事

1. **签名不能去掉**：Apple 芯片上所有可执行代码至少要有 ad-hoc 签名才能跑，去掉签名不是"少一个弹窗"，
   而是**根本打不开**（系统改说"已损坏"）。
2. **签名 + 公证都齐，第一次打开也仍会弹一下**，只是换成带「打开」按钮的那种（点一下就进）。
   公证需要 Apple 开发者证书（99 美元/年）；在那之前，上面两条路就是"完全不弹"的正解。
