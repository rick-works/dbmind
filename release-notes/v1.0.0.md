# v1.0.0

> 首个正式版 —— 给数据库装上「大脑」的 AI 数据库工作台

发布日期：2026-09-28
类型：正式版

## AI 全程加持

- **SQL 解释**：选中语句逐段讲清在做什么、影响哪些表
- **优化建议**：给出改写建议与索引建议，可先看执行计划对比再落地
- **报错自动修复**：报错后一键让 AI 修复并回填编辑器
- **性能诊断 / 智能问答**：结合当前库结构给出可执行答案
- AI 给出的 SQL 先「看执行计划、试跑一次」再落地

## 多数据源统一管理（17+ 种）

| 类别 | 支持 |
|---|---|
| 关系型 | MySQL、PostgreSQL、Oracle、SQL Server、MariaDB、DB2、Derby |
| 国产 | 达梦 DM、人大金仓、Apache Doris |
| 分析与分布式 | ClickHouse、Doris |
| NoSQL 与搜索 | Redis、MongoDB、Elasticsearch |
| 嵌入式 | SQLite、H2、DuckDB |

## 事务模式与结果集直接编辑

- **事务模式**：一键关闭 autocommit，写语句挂起不提交 —— 改完自查、满意提交、不满意回滚
- **结果集直接编辑**：双击单元格改值、攒缓冲、一次提交，WHERE 条件自动生成
  （优先主键，否则全列定位）；翻页重跑后过期缓冲自动作废，绝不改错行

## 智能 SQL 编辑器

- Monaco（VS Code 同款内核）内核：上下文补全、格式化、多语句分块执行、逐段计时条
- SQL 片段库、模板变量（:name 占位符，执行前弹窗填参）、执行历史

## 千万级结果集秒开

- 虚拟滚动 + 服务端分页 + 响应压缩（实测 4.2MB → 233KB，18×）
- 总数异步统计不阻塞数据回显，大 JOIN 也能 1 秒见数

## 数据透视与传输

- 框选即汇总（计数 / 求和 / 均值 / 最值）、分组下钻透视
- 导出 CSV / Excel / JSON / INSERT，长任务后台执行、完成系统通知

## 安全护栏

- 生产连接显式标识（PROD 标记），一眼可辨
- 写操作二次确认、单查询超时与行数预算、执行审计留痕
- 全程本地运行，数据不出你的网络
