# v1.0.0

> 首个正式版 —— 给数据库装上「大脑」的 AI 数据库工作台

发布日期：2026-09-28
类型：正式版（第一次发布）

## AI 全程加持

- **SQL 解释**：选中语句，逐段讲清它在做什么、会影响哪些表
- **优化建议**：给出改写与索引建议，可先看执行计划对比再决定用不用
- **报错自动修复**：执行报错后一键让 AI 修好并回填编辑器
- **性能诊断 / 智能问答**：结合你当前的库结构给出能落地的答案
- AI 写的 SQL 可以先「看执行计划、试跑一次」再真正执行 —— 猜错的东西进不了你的库

## 一个工作台管住 17+ 种数据源

| 类别 | 支持 |
|---|---|
| 关系型 | MySQL、PostgreSQL、Oracle、SQL Server、MariaDB、DB2、Derby |
| 国产 | 达梦 DM、人大金仓、Apache Doris |

| NoSQL 与搜索 | Redis、MongoDB、Elasticsearch |
| 嵌入式 | SQLite、H2、DuckDB |

## 事务模式 + 结果集直接改

- **事务模式**：一键关掉"改一句就生效"，写操作先挂起 —— 改完自查、满意提交、不满意回滚
- **结果集直接编辑**：双击单元格改值，攒够了再一次性提交（程序自己拼好定位条件，
  优先用主键）；翻页或重跑后过期的改动会自动作废，绝不会改错行

## 智能 SQL 编辑器

- 编辑器内核与 VS Code 同款：上下文补全、一键格式化、多语句分块执行、每段单独计时
- 常用语句可存为片段；支持模板变量（执行前弹窗让你填参数）；执行历史随手翻

## 上千万行的表也一秒见数

- 打开大表不必等它全部取完：只取当前屏幕需要的部分，实测响应体从 4.2MB 压到 233KB
- 总条数在后台慢慢算，不挡着你先看数据

## 数据透视与前后搬运

- 框选即汇总（计数 / 求和 / 均值 / 最值），可分组下钻
- 导出 CSV / Excel / JSON / INSERT；耗时长的导出放后台跑，完成后系统通知你

## 安全护栏

- 生产库可以标记为「生产」，界面上处处可见，不会误操作
- 写操作二次确认、单次查询有时间与行数上限、所有执行都留痕可查
- **全程本地运行，数据不出你的网络**
