## 更新说明

- SQL 编辑器：`BEGIN TRAN` / `BEGIN IMMEDIATE` 不再把后面的语句吞成一条，MySQL 行首 `# 注释` 正确识别（里面的分号不切语句），中文表名也能进「编辑目标表」下拉
- 只读连接：CTE 里用换行或 Tab 藏着的写语句、`SELECT ... INTO`、`nextval` / `setval` 这类会改序列的 SELECT 现在一律拦下
- 事务：带着未提交修改的连接不再被后台空闲回收，连接失联时直接报错而不是静默重连（以前会连带把事务丢掉）
- 取消：多语句批次在语句之间就响应，长脚本点「取消」不用等当前语句跑完
- 结果集就地编辑：标识符按各库规范加引号（中文列名、保留字不再报错），字符串按方言转义（MySQL / ClickHouse 里的反斜杠不再被吃掉）
