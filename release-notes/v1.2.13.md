## 更新说明

- SQL 格式化新增两处可配项：「逗号位置」（字段后 / 字段前）与「缩进风格」（标准 / 表格左对齐 / 表格右对齐）
- 「关键字排版规则」新增「缩进宽度」列：可对每个关键字单独配，留空跟随全局，填 0 表示不缩进
- 编辑器右键菜单新增「编辑器设置 / 格式化设置」，点一下直达对应设置页
- 设置面板观感优化：规则改成带边框的表格，控件对齐与字号和其它设置页统一
- 「通用」新增界面尺寸：可调顶栏菜单文字（含前面的图标）、顶栏右侧图标与左侧树文字大小，改完立即生效
- 设置项归置：「主题」与「通知」两页并进「通用」（都属于全局界面与行为偏好），设置菜单更短
- 修复「脚本页签偶发一片空白」：Monaco 加载失败后不再被永久缓存，并给出可操作提示
