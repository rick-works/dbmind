## 更新说明

- 字段脱敏（新）：按「表 + 列」把敏感值换成 MD5 / SHA-256 摘要或 AES-256 密文（密钥存本机、可解回原文），一份规则四个开关 —— 发给 AI 的内容（上下文样例行 + 智能体只读结果）、MCP 客户端拿到的数据、结果表格的显示、导出的 CSV / Excel / JSON / SQL 文件；库里的数据一个字节都不改，表名列名注释与 SQL 里手写的字面量不脱敏
- 结果表格右键多了「复制为 IN (...)」：选中一列直接得到 IN 参数（多列按列分段、段前标列名），字符串按目标方言转义 —— 上百个 id 不用再手工补引号
- SQL 编辑器右键可直接「保存片段 / 插入片段 / 清空片段」：选中 SQL 命名保存到本机、跨会话保留；顶部「片段」下拉只留查看与插入（去掉重复的「存为片段」按钮），存盘失败会明说而不是静默
