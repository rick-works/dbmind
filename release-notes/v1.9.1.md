## 更新说明

- 修复「脚本管理」里重命名 / 删除不生效：列表行的表格 id 曾被当成脚本 id 传下去，改名弹「脚本已不存在」、删除提示成功后脚本仍在 —— 现在打开、重命名、删除三条动作都按真实脚本 id 定位
- MCP 不再把 SSH 隧道口令交给模型：「列出连接」返回里的 ssh.password / keyPassphrase 一律替换为 ***（数据库口令本来就只写不读）—— 工具描述写的「不含口令」，现在名副其实
- 不装 JDK 也能用 CLI / Web / MCP：内核优先采用可执行文件旁自带的 jre（与桌面版同一份，≥17 才用），不必再手设 DBMIND_JAVA；Windows 安装包也把 dbmind（CLI）、dbmind-web、dbmind-mcp 与桌面版一起装进安装目录，装完四端齐用
