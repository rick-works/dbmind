## 更新说明

- 全项目「选择连接」下拉改成「分组 → 连接」两级：组头可点开收起，打开时自动展开当前连接所在的那一组（SQL 编辑器 / 数据传输 / 数据对比 / 用户管理 / 对象清单 / 数据治理 / AI 命令面板，共用同一个组件和同一份样式）
- 下拉里只显示连接名 —— 右侧那一列 MySQL / PostgreSQL 类型后缀全部去掉，文字统一 13px（组头原来是 12px 加粗，和成员看着不像一套）
- 连接选择框宽度改为按选中的名称自适应（不再写死 180 / 260px），长名字不截断、短名字不留大片空白；顺带修掉「质量规则」页占位文字灰得看不清，工具栏统一到 12px
