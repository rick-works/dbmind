## 更新说明

- SQL 编辑器：不写分号也能正确识别多条语句，光标所在语句有框线、点「执行」只执行这一段；存储过程、触发器、CTE、PG 美元引号函数等复杂 SQL 不再被切错
- SQL 格式化：语句之间的空行严格按设置生效（有没有分号都一样），多条语句逐条格式化，注释与分号不丢
- 连接与导入：重新展开已打开的连接前会先校验，连不上立即提示并收起；文件导入按目标列类型写值（Derby 数值列不再失败），Derby 表可重命名；Oracle / DM 的搜索与 ER 图按模式查询，不再枚举全部模式
