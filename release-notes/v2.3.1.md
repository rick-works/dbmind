## 更新说明

- 修复 PG 触发器备份：导出的删触发器语句现在带上所属表，还原时不再报语法错。
- 跨库同步更稳：数据里的 t/f、yes/no、on/off 能正确写入布尔列；Doris 带 catalog 的库名不再数错行；Oracle/达梦的「存在就更新」批量写入不会再因个别脏行中断；长任务取消和 AI 流式回复断线时不再继续占用连接或白耗 token。
- DB2 / Derby / DuckDB / H2 补齐模式支持：同步、对比、脱敏等页面能像其它库一样选「模式」；ClickHouse / Doris / Databend 的模式声明也按真实能力修正，避免 MCP 把带点的库名拆错。
