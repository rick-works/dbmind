# v1.0.1

> 审计日志全面增强 + 设置界面重构 —— 日志终于「看得到、筛得清、抄得走」

发布日期：2026-10-06
类型：修订版（功能增强与体验修复，不含破坏性变更）

## 审计日志

- **按类别筛选**：查询操作 / 数据操作 / 表操作 / 事务操作 / 其他执行 / AI 操作 / 失败操作 / 不展示，
  在服务端做 SQL 级过滤，不是前端过滤，所以翻页与计数都对得上
- **一键复制 SQL**：每条日志右侧常驻复制按钮，点了整条 SQL 进剪贴板（非 HTTPS 环境自动回落 `execCommand`）
- **真实总条数**：新增 `count_logs` 接口，日志面板返回同条件下的准确总数，
  「共 N 条」与分页页数不再靠前端估算（此前固定显示 50 条、只有 1 页）
- **不再自动清理**：审计日志只在点「清空日志」时一次清空全部记录（执行历史 + AI 调用），
  启动时和每次执行都不再自动 prune —— 不会在你没察觉时丢掉想留的记录
- **AI 调用纳入保留策略**：`ai_audit` 与执行历史共用同一套条数 / 天数规则，长期使用不会无限增长
- 合并原「记录级别」与「来源」两个控件为一个「日志类别」下拉，语义更清晰

## 设置界面

- **弹窗高度跟随视口**（`calc(100vh - 190px)`）：去掉会撑破屏幕的 640px 下限，
  弹窗右侧那道让人抓狂的竖向滚动条消失；窄视口下宽度自适应 `min(1200px, 96vw)`，右侧内容不再被裁
- **日志页签**：列表吃满剩余空间并在内部滚动，分页条常驻可见（此前列表撑破布局把分页挤出可视区）
- **关于页**：新增「目录说明」板块（数据目录 / 驱动目录 / 日志目录）；
  版本号改为语义化三段展示（大版本 . 小版本 . 修订，悬停每一段看含义）
- **版本说明**：支持多版本时间线 —— 类型标签（正式版 / 修订 / 小版本 / 大版本）、发布日期、
  跨版本列对齐、节点圆点与竖线
- 菜单顺序调整：快捷键移到「格式化」之后

## 工程

- 版本号 **1.0.0 → 1.0.1**（`Cargo.toml` / `package.json` / `tauri.conf.json` 同步）
- 新增 `scripts/release.mjs`：一键发版 —— 同步三处版本号、插入新版本说明骨架（旧版本自动顺延），
  支持 `--dry-run` 预览
- 版本号规则确立并落地在界面提示中：从 1.0.0 起，修 bug / 优化只加修订号，
  新增功能加小版本，不兼容的重大变更才加大版本

## 升级提示

- 无破坏性变更，直接升级即可
- 建议升级后点一次「清空日志」，从此日志只在你主动清空时才会消失
