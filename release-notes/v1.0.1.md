# v1.0.1

> 审计日志全面增强 + 设置界面重构 —— 日志终于「看得到、筛得清、抄得走」

发布日期：2026-10-06
类型：修订版（体验增强与修复，不影响已有用法）

## 审计日志

- **按类别筛选**：可按「查询操作 / 数据操作 / 表操作 / 事务操作 / AI 操作 / 失败操作」等类别筛选，
  翻页和「共 N 条」都对得上（筛选是在数据端完成，不是只筛当前这一页）
- **一键复制 SQL**：每条日志右侧都有复制按钮，点一下整条语句进剪贴板
- **总条数是真的**：「共 N 条」给的是准确数字，不再靠估算
- **不再自动清理**：日志只在你点「清空日志」时才会消失 —— 以前启动和执行时会悄悄丢掉老记录，
  现在不会了
- **AI 操作也纳入保留规则**：长期使用不会无限增长
- 原来「记录级别」和「来源」两个下拉合并成一个「日志类别」，少一次选择

## 设置界面

- **窗口不再被撑破**：弹窗高度跟着窗口走，右边那道多余的滚动条没了；窗口拉窄也不会裁内容
- **日志页签**：列表在内部滚动、分页条始终可见
- **关于页**：新增「目录说明」（数据、驱动、日志各自放在哪）；版本号按「大版本 · 小版本 · 修订」分段显示
- **版本说明**：改成了跨版本的时间线，标出类型（正式版 / 修订 / 小版本 / 大版本）与发布日期
- 菜单顺序微调：快捷键挪到「格式化」后面
