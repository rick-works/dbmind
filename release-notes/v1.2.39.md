## 更新说明

- 编辑表结构：长度 / 精度两格不再显示「可选 / 必填 / 精度」这类提示，所有数据库、新建表与编辑表结构两个页面完全一致；「项目 / 值」与表头统一字体字号（表头只加粗），新建表的「复制 SQL / 执行创建」统一到底部
- ClickHouse 引擎下拉直接给出可落进 SQL 的完整写法（`MergeTree()` 带括号、`Log` 不带，并补全 Replicated 系列），新建表与编辑表结构共用同一份清单，生成 SQL 时不再按名字猜着补括号
- 「索引类型」真正落进 SQL：MySQL 的 FULLTEXT / SPATIAL / USING HASH、Doris 的 USING、Oracle 的 BITMAP、SQL Server 的 CLUSTERED；没有索引类型概念的库（SQLite / H2 / Derby / DB2）不再显示这一列
- 修复无分号拆分把建表末尾的 COMMENT 切成两条语句（ClickHouse 会报 failed at position 1），MySQL 的 `COMMENT='…'` 表选项同办
