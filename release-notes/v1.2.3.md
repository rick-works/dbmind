# v1.2.3

> 只为一件事：把 macOS 的 **DMG 安装页**修成正经的「拖进应用程序」—— app 里的东西一行没动

发布日期：2026-10-11
类型：修订版（仅打包方式，无代码变更）

## DMG 为什么一直长得不对

Tauri 在 CI 上会给 `create-dmg` 传 `--skip-jenkins`，**跳过**"设置窗口背景与图标位置"的那段
AppleScript —— 原因是 headless 的构建机上 Finder 自动化不可靠。跳过的结果就是：DMG 打开以后
两个图标堆在窗口左上角，没有留白、没有动线，看着完全不像"拖过去安装"那种。

v1.2.2 里我先是用 `dmgbuild` 换掉它（它**自己写 `.DS_Store`**、不经过 Finder，所以能在 CI 上用），
但装依赖那一步被 runner 的 Python 拦了 —— Homebrew 的 Python 受 **PEP 668**
（`externally-managed-environment`）保护，`pip install --user` 直接报错，于是静默退回 Tauri 原样，
DMG 依旧是老样子。这一版把依赖装进 **venv** 绕开它（venv 不可用时退到 `--break-system-packages`），
并给镜像显式指定 `UDZO` 压缩（dmgbuild 默认不压缩，不写会比 Tauri 那个大好几倍）。

现在 DMG 打开就是：左边 `DBmind.app`、右边「应用程序」软链，窗口 660×400，图标按预设位置摆放，
拖一下即可安装。

## 上一版的两处修复仍在本版里

- **打开不再黑屏**：打包进去的资源（`web/`、`agents/`、`jre/`）改为按平台资源根查找
  —— macOS 在 `.app/Contents/Resources/`，不再是"只在可执行文件旁边找"。
- **自带 Java 运行时能被识别**：java 可执行名按平台取（macOS/Linux 是 `java`，不是 `java.exe`）。

## 关于「不执行那条 sudo 命令就能打开」

```bash
sudo xattr -dr com.apple.quarantine /Applications/DBmind.app
```

它去掉的是 macOS 给"网上下载的文件"打的隔离标记；App 未签名/未公证时，系统就会拦一道。
**这是 macOS 的规则，应用自己绕不过去。** 右键 →「打开」可以放行一次（不放心的话只做这一步就够，
不必用 sudo）。

要真正做到"下载完双击就能开"，需要 **Apple 开发者证书（99 美元/年）+ 公证**。
打包流程这边**已经备好**：`.github/workflows/release.yml` 会读仓库 Secrets 里的
`APPLE_CERTIFICATE` / `APPLE_CERTIFICATE_PASSWORD` / `KEYCHAIN_PASSWORD` 自动签名，
再配上 `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` 就自动公证 —— 证书到手后只需填这 6 个 Secrets。

## 安装包（全平台）

| 平台 | 文件 | 形态与适用场景 |
|---|---|---|
| Windows | DBmind_1.2.3_x64-setup.exe | 安装向导（推荐） |
| Windows | DBmind_1.2.3_x64_en-US.msi | MSI 包（企业批量部署 / 静默安装） |
| Windows | dbmind-1.2.3-portable.zip | **免安装**：解压即用，不写注册表 |
| macOS（Apple 芯片） | DBmind_1.2.3_aarch64.dmg | 安装镜像：把图标拖进「应用程序」 |
| macOS（Intel） | DBmind_1.2.3_x64.dmg | 安装镜像：把图标拖进「应用程序」 |
| Linux（Debian / Ubuntu） | DBmind_1.2.3_amd64.deb | apt 安装，带开始菜单项 |
| Linux（通用发行版） | DBmind_1.2.3_amd64.AppImage | **免安装**：`chmod +x` 后直接运行 |

- 每个包都自带精简 Java 运行时（目标机器不必另装 Java）。
- 未配置签名证书：macOS 首次打开需右键「打开」或在「隐私与安全性」放行，Windows 会提示「未知发布者」。

## 升级提示

- 已经用上 v1.2.2 且能正常打开的用户：这一版**只有安装包外观的变化**，不升也完全没问题。
- 想省事（不想看到"图标堆在左上角"那种安装页）：换这一版即可。
- 无破坏性变更，连接、脚本与设置全部保留。
