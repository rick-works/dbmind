## 更新说明

- 「每批行数」现在放到界面上（同步 → 选项），按目标库填好默认值，也可以自己改：ClickHouse 10000、PostgreSQL / Doris 2000、MySQL / MariaDB / SQL Server / Oracle / 达梦 / DB2 1000、SQLite / H2 / Derby 5000 行一条
- 单条语句的字节上限也按库分开：ClickHouse 与本地库 8MB、MySQL / MariaDB 1MB、Doris 512KB、其余 4MB；起步仍是 512KB，实测每条语句够快就自动翻倍，慢就自动缩小
- 宽表先被字节上限切开，Oracle / 达梦 / DB2 另受「派生表表达式 65535 个」限制（130 列时约 504 行/条），所以上面的行数是上限、不是承诺
- 事务段从 50 万行降到 **10 万行**提交一次：提交开销仍是百分之一量级，但断开时要回滚的只有 10 万行，重跑快得多，也避免大事务「越写越慢」
- 任务第一行日志会写「每批最多 N 行」，界面填的值有没有生效一眼可验
