## 更新说明

- 指向外部 catalog 的库（如 Doris 里指向 ClickHouse 的 jdbc catalog）可以正常打开数据浏览了：列清单、高级搜索、关键字模糊搜索、翻页全部可用（以前直接报「暂不支持外部 catalog」）
- 兼容 Oracle 11g：数据浏览与翻页不再报 ORA-00933，分页改用各版本都支持的写法
- 修复 SQL 尾部分号在 Oracle 上报 ORA-00911、下划线开头的表名（如 _report_xxx）打不开的问题
