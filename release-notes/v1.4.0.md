## 更新说明

- 传输参数新增可调的并发三项：并发表数、每表读并发、每表写并发，都能选「自动」或指定 1~16 —— 链路差、目标库吃紧想更稳时自己降到 1，默认仍按库类型与表数自动切预算
- 同步完成行能看出时间花在哪：「N 批，平均每批 X 秒」判断是不是每批的固定开销，「其中等待超时/重连 Y」判断是不是链路在拖；耗时改为计入整表重跑的全部轮次
- 每批条数与两条限速改成下拉，随时能选回「自动 / 不限制」；写超时时若这一批只有几十 KB，不再缩小页（报文不是原因时缩页只会让批数翻倍、越跑越慢）
- 同步报错只带数据库/驱动的原话：去掉「开启事务失败：」「提交事务失败：」这类前缀，这些上下文只进文件日志
- 任务中心的同步标题：两端库名相同时压成「A → C / 库」，不再出现两个名字完全一样、分不清谁是谁的任务
