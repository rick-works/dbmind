## 更新说明

- 备份导出改用多值 INSERT：20 万行的备份文件里 insert 语句从 20 万条降到 200 条，文件体积也小了一半
- 还原提速：同一份 20 万行备份从「一个多小时」降到 20 秒；旧版本导出的「一行一条 INSERT」备份会在执行前自动合并，不用重新导出
- 同步写入走 JDBC 预编译批处理（SQL Server / Oracle / 达梦 / H2），decimal 保留到小数点后全部位数，不再因浮点转换丢尾数
- 同步与对比的小优化：小表对比直接在内存里做哈希（不落临时文件）；upsert 对空目标表改用 limit 1 探测；分页行数按实际行宽自动调整
