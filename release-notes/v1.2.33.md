## 更新说明

- 用户管理页改版：拆成「用户管理 / 角色管理」两个页签，角色可以新建、删除，并直接以角色为主体授权；没有角色概念或版本不支持角色的库（SQL Server、SQLite、MySQL 5.7 等）只显示「用户管理」
- 角色的权限读回补齐：MariaDB 的角色改读 SHOW GRANTS（信息架构视图不列角色），PostgreSQL / KingbaseES 从 ACL 与 pg_auth_members 解出权限和成员关系（能回显也能撤销），MySQL 角色以「名字@主机」打开不再报「没有找到用户」
- Oracle / 达梦不再显示「库」这一层：对象列表、SQL 编辑器、对比 / 同步 / 备份、ER 图、监控与 AI 面板里的服务名与库下拉一并去掉，只留模式；顺带修好 Oracle 的模式下拉恒为「无数据」
- 修好 Oracle 点开表看不到字段（ORA-17027）：列信息改在切到目标模式后按驱动要求读取（COLUMN_DEF 先读），达梦不受影响
- NoSQL 的占位库 (default) 在 SQL 编辑器里显示为「默认」
