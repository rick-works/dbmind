## 更新说明

- 「编辑表结构」现在能调字段顺序：在字段表里选中一行，用工具栏的「上移 / 下移」移动，SQL 预览同步给出 ALTER 语句 —— MySQL / MariaDB / Doris 是真的改表（Doris 的分桶列会置灰并说明原因），建表后列顺序固定的库（ClickHouse / PostgreSQL / Oracle / SQL Server / DB2 / H2 / Derby）直接不显示这两个按钮，免得点了报错
- 「类型」那一格改成可输入 + 可选择：下拉里挑也行，直接敲 character varying(64)、decimal(10,2) 这类带参数的类型也行，粘贴进去就生效、不用回车（新建表与编辑表结构同一套）
- 新建表的 SQL 预览加了可拖动分隔条：上下拖动调高度、双击在最大与还原之间切换、点标题行收起；预览底色也和「编辑表结构」统一了
