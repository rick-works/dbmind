## 更新说明

- Windows Server 2012 R2 兼容性：老系统自动关闭 WebView2 的 GPU 合成（实测 CPU≈0% 的窗口卡死/画面不刷新），WebView2 数据目录隔离到用户目录，顶栏补齐上边缘系统边框
- 没有数据源时也能直接点开「知识库」和「AI 助手」——之前空态页把页签渲染整个挡住了，点了没反应
- 编辑器工具条 ResizeObserver 自激修复：拖窗口/点按钮不再可能卡死；工具条级数改用二分计算，重排次数从最多 11 次降到 4 次
