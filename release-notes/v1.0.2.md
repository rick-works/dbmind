# v1.0.2

> 在线更新终于能用 + 下载可以放后台 —— 以前"点了没反应"的更新，现在能下载、能装好

发布日期：2026-10-07
类型：修订版（体验修复与增强，不影响已有用法）

## 在线更新

- **配了代理也能下载**：自动识别系统代理（Windows / macOS / Linux 都支持）—— 以前在代理环境下点更新
  就是一直下载不动，现在会自动走代理；探测不到可用代理时，也不会把其它请求一起拖住
- **自己选存在哪**：点「在线更新」会先弹出目录选择框，选好才开始下载
- **看得见进度**：进度条 + 已下载 / 总大小 + 实时速度，下载在后台进行，界面不卡
- **可以放后台**：关掉进度窗，下载继续进行；顶栏的更新图标上会显示任务角标，点一下随时把进度窗调回来
- **下载完自动装**：校验通过后自动拉起安装器，装完重开就是新版
- 私有仓库场景：带令牌被拒绝时会自动匿名重试一次，不再直接失败

## 界面

- **下载角标**：顶栏「检查更新」图标右上角显示进行中的任务数，进度窗开着或切到后台都能一眼看到
  （顺带修掉"一打开应用就显示有任务在跑"的假提示）
- **更新说明能正常排版**：表格、列表都按原样显示，内容太长会折叠成「查看完整更新说明 →」
- 修掉更新说明里列表被拆成两段的问题

## 装机反馈修复（同版本重新打包）

- **Doris 连不上**：打包自带的精简运行环境少了一个字符集模块，连 Doris 时会直接报
  「Unknown character set: 'eucjpms'」—— 表现为"Doris 连不上、MySQL 正常"。已补上，
  并把 Doris 的驱动换成与 MySQL 同一版本
- **启动 / 连接时闪黑窗**：已修，不再弹出黑色命令行窗口
- **首页 KPI 面板**：空态首页顶部恢复「总连接数 / 已连接数 / 连接类型」三格，
  一眼看清有多少数据源、活着几条
- **驱动下载显示进度**：新建数据源点「测试连接 / 保存」、设置里点「下载驱动」时都会显示进度条与
  已下载大小 —— 几十兆的驱动在慢镜像下不再像卡死
