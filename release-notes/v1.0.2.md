# v1.0.2

> 在线更新打通 + 下载任务角标 —— 更新器终于能在真实网络（代理环境）下跑通了

发布日期：2026-10-07
类型：修订版（体验修复与体验增强，不含破坏性变更）

## 在线更新

- **走系统代理下载**：新增跨平台代理探测 —— 环境变量优先，其次 Windows 注册表
  （`HKCU\...\Internet\Settings`， accelerators / Clash 开启即自动生效）、
  macOS `scutil --proxy`、Linux `gsettings`；探测通才复用，配置了代理但实际不通时不把所有请求一起拖死
- **自选保存目录**：点「在线更新」后弹系统目录选择框（Windows PowerShell `FolderBrowserDialog`、
  macOS `osascript`、Linux zenity / kdialog），选完才开始下载；目录只作本次生效，不做自动清理
- **下载进度**：进度条 + 已下载 / 总量 + 实时速度；下载在后台线程池执行，不阻塞界面
- **可放后台**：关掉进度窗不中断下载，顶栏刷新图标挂任务角标，点一下随时把进度窗调回来
- **完成即装**：下载校验通过后自动拉起安装器，装完关掉应用重开即是新版
- 私有仓库场景：带令牌请求被拒（401/403）时自动丢弃令牌匿名重试一次，不再直接失败

## 装机反馈修复（同版本重新打包）

- **Doris 连不上**：打包用的精简 JRE 由 jlink 生成，缺 `jdk.charsets` 模块。
  MySQL Connector/J 握手时要把服务端 collation 映射成 Java 字符集，Doris 的 collation 表里有
  `eucjpms`，缺模块直接报 `Unknown character set: 'eucjpms'` —— 表现为「Doris 连不上、MySQL 正常」。
  模块集补上 `jdk.charsets`；同时把 Doris 的驱动换成 `mysql-connector-j:9.1.0`（与 MySQL 一致）
- **启动/连接时闪黑窗**：桌面壳是 GUI 子系统程序，未隐藏控制台的子进程会自己弹黑窗。
  已给 `java -version`、读系统代理的 `reg`、在线更新选目录的 `powershell` 统一加 `CREATE_NO_WINDOW`
