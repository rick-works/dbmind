## 更新说明

- 桌面版「选择文件」改用系统自带的文件管理器：还原数据库选备份文件、连接 SQLite / H2（文件）/ Derby（目录）都直接弹系统对话框，不必再在页面里的目录树里逐级点
- 系统对话框按类型过滤（.sql / .dump / .backup / .gz / .zip，.db / .sqlite / .mv.db 等）并记住上次打开的目录，选完立刻回填绝对路径
- 浏览器打开的 Web 版保持原来的「后端列目录」浏览方式（浏览器不提供本机绝对路径），桌面版不再需要它
