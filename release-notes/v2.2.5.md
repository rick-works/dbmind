## 更新说明

- Windows Server 2012 R2 上不再额外绘制顶栏浅蓝补边，窗口四周框线与 Win11 保持一致
- 修复顶栏菜单在拖窗口到窄尺寸时可能卡死：宽度自适应改为每帧合并计算 + 二分求档，减少强制重排
- 加固 AI 面板底部工具条的同类卡死风险：ResizeObserver 改为观察外层容器，压缩档位改二分且不再重复写 DOM
