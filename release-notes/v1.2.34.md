## 更新说明

- 新建 / 编辑数据源表单统一：必填字段带星号，可留空的在输入框里标「可选」，不用再猜
- 连接超时默认 10 秒、读取超时默认不限，所有数据库一致；相关提示统一并缩短
- Oracle：「连接方式」挪到服务名上方，默认服务名，标题跟随选择显示服务名 / SID，并去掉多余的必填占位提示
- SQL Server 去掉「实例名」，统一填主机与端口（命名实例填它实际监听的端口）
- 空库名的 JDBC URL 更干净：MySQL / Doris / ClickHouse 不再拖尾斜杠，PostgreSQL / Kingbase 保留（驱动语法要求）
