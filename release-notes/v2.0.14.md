## 更新说明

- 结果表头排序改成真·全表排序：把 ORDER BY 交给数据库重新查询，不再只排当前已加载的这一页 —— 几百万行的表终于能一眼看到最新 / 最早的那几条；SQL 里自带 order by、limit、union，或末尾带分号、行内注释都不影响
- 多段语句（分号分隔的多条 SQL）也对齐了：点排序只重跑你正在看的那一段，其它结果集原样保留，不会把写入语句再执行一遍
- 修一个排序方向的 bug：有时点出 ↓ 却仍按升序查（箭头和结果对不上）
