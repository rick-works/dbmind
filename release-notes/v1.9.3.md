## 更新说明

- MCP 多了「库」这一层：表清单 / 搜表 / 表结构可以带库名（SQL Server、PG 再带模式），设置里还能给默认连接配一个「默认库（+模式）」，AI 不用每次先列库再猜 —— 换库只在内存里做，不再往连接列表里塞一堆影子连接
- 连接没绑定库时 MCP 直接说明原因：以前 MySQL 会「成功地」返回 0 张表，AI 据此认定这个库里没有表，转头去几百条连接里瞎猜
- 设置页的「默认连接 / 默认库 / 模式」下拉宽度跟着内容走：打开就按名字撑开，长库名不再被截成「information_sch…」
