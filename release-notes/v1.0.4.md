# v1.0.4

> 后台任务卡住时，现在会**如实告诉你**，而不是没完没了地转圈

发布日期：2026-10-09
类型：修订版（修问题，不改用法，直接升级）

## 数据传输：卡住的任务不再"悄悄挂住"

**你可能遇到过的现象**：一次数据传输跑了 21 分钟，界面一直显示
「任务仍在后台收尾，已允许关闭窗口」。关掉窗口没用，点「停止」也没用，刷新回来它还在那儿 ——
看着像"还在跑"，其实它早就走不下去了。

**为什么会这样**：程序只在"每读完一页、每写完一批"的空隙里，顺便看一眼你有没有点停止。
如果任务恰好停在"等对方回话"那一步（最常见的是网络切换、或者对方断开之后），
它就永远轮不到那次检查 —— 于是一个其实已经失败的任务，会一直显示成"正在运行"。

**这次改了什么**：

- 所有"等对方回话"的环节都加上了明确的时间上限，不再无限期等下去。
- 真的卡住时，任务会自己结束，并告诉你**具体卡在哪**，例如
  「下游 11 分钟没有取走数据，判定连接可能已断开」——而不是只丢一句"失败"。
- 兜底：万一还有没照顾到的情况，30 分钟后也会自动结束，并在日志里记下它停在哪一步。
  **已经写进库里的数据会保留，不会被回滚。**
- 该快的地方一点没变慢：只有"等不到回应"才会结束，"慢慢跑"照常跑完。

## 安装包（全平台）

按平台与使用习惯挑一个即可 —— **每个包都自带精简 Java 运行时**，装完就能连库，不必另装 Java。

| 平台 | 文件 | 形态与适用场景 | 大小 |

## 首次安装与打开

三个平台都是标准安装包，**装完即可用**；只因为本版还没有花钱买签名证书，系统会先礼貌拦一下 ——
按下面放行即可，不影响任何功能：

- **Windows**：出现「Windows 已保护你的电脑 / 未知发布者」时，点「更多信息」→「仍要运行」。
  安装向导与 MSI 都能正常安装；免安装 zip 解压后直接运行 `start.bat`，没有这类提示。
- **macOS**：出现「无法验证开发者」时，在「访达」里**右键（或按住 Control 点击）应用 → 打开 → 再点「打开」**。
  如果见到「已损坏，无法打开」（Apple 芯片上偶尔出现），执行一次下面这行就好：
  ```
  sudo xattr -dr com.apple.quarantine /Applications/DBmind.app
  ```
  放行一次之后，以后每次都正常打开。
- **Linux**：`.deb` 双击安装即可（提示缺依赖时补一句 `sudo apt -f install`）；AppImage 先 `chmod +x` 再运行。
- 等签名证书办好，后续版本会变成"双击即开、不再有任何提示"，下载渠道和文件名都不变。
