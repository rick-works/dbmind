# v1.2.9

> 更新流程少两次打断：不再问你装到哪（固定落系统「下载」）、Windows 上不再停在「已安装」那一页；页签条也只留表名了

发布日期：2026-10-11
类型：修订版（无破坏性变更）

## 在线更新：不再让用户选位置

以前点「在线更新」，第一件事是弹系统的「选择文件夹」对话框，而且默认值还是**系统临时目录** —— 想找那个安装包得去 `…\AppData\Local\Temp\dbmind-update\` 里翻。

现在点一下就直接开始下载，安装包固定落**系统的「下载」目录**：

- 三个平台一致（macOS 的 dmg、Linux 的 deb 同样落「下载」）
- Windows 上走的是系统 Known Folder 接口：把「下载」重定向到别的盘、或被 OneDrive 接管，也能落对地方（拼 `%USERPROFILE%\Downloads` 在那种机器上会指向不存在的目录）
- 拿不到标准下载目录时依次退到「家目录/Downloads」「临时目录」，保证任何环境都下得动
- 下载完成后点弹窗里的「打开所在文件夹」即可直达

## Windows 更新：不再停在「已安装」那一页

Windows 用 NSIS 安装包更新时，只要检测到装过旧版本，就会弹一页问「先卸载 / 不卸载」，而且默认勾的是「先卸载」（那会跑一遍旧卸载程序，有清掉配置的风险）。

现在这一页**不再出现**：更新器启动安装包时会带上 passive 与 update 参数 —— 只剩一条进度条，原地覆盖安装（连接、脚本、设置全部保留），装完自动把新版拉起来。装到带空格的路径（例如 `C:\Program Files`）也不会再被拆开（顺手补了引号）。

## 页签条：只显示表名

页签上原来是「连接 · 库 · 表名」一整条。现在只显示**表名 / 对象名**，把鼠标停在上面就能看到完整路径。

需要说明：**确认类对话框仍然用完整路径**（关闭未保存的页签、切换连接、退出等，共 5 处）—— 那时候必须分得清是哪个连接、哪个库，缩成表名会让人对不上号。

## Linux 用户注意

- `.deb`：`sudo apt install ./DBmind_1.2.9_amd64.deb`；提示缺依赖时补一句 `sudo apt -f install`。它依赖 `libwebkit2gtk-4.1`，所以 Ubuntu 22.04+ / Debian 12+ 直接装。
- `.AppImage`：先 `chmod +x`。它需要 **libfuse2**（Ubuntu 22.04 起默认只带 fuse3）—— 双击没反应就 `sudo apt install libfuse2`，或者 `./DBmind_1.2.9_amd64.AppImage --appimage-extract-and-run` 免挂载运行。

## 升级提示

- **装这一版时用的还是旧客户端**，所以那一次仍会弹「选择保存位置」与 Windows 那一页；从这一版装好之后，再更新才是「不选位置、不弹页、装完自动回来」。
- 无破坏性变更，连接、脚本与设置全部保留。
