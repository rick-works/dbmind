## 关闭窗口时会先问一句

点右上角 ×（或按 Alt+F4、在任务栏右键关闭、macOS 点红点）时，不再直接退出，而是问一句：

| 选择 | 会发生什么 |
|---|---|
| **最小化到托盘**（回车默认） | 窗口收进托盘，应用继续在后台运行；点托盘图标就能把窗口叫回来 |
| **关闭** | 真正退出 DBmind（照旧会清理后台的数据库宿主进程） |
| × / ESC | 取消，窗口保持原样 |

**三个系统是同一套行为**，没有任何平台差异 —— 因为拦的是系统级"窗口要关了"这个事件，
所有关闭途径都经过它。这一点很重要：只在界面上拦自绘的那个 ×，其余途径会绕过询问直接退出。

回车默认落在「最小化到托盘」这一侧，是因为它是**可逆**的那个选择：误按一下不会丢工作现场，
要退出就明确点「关闭」。

## 新增托盘图标

既然能"最小化到托盘"，就必须留一条回去的路，否则窗口一收就再也叫不出来：

- **左键点托盘图标** → 把窗口叫回来（Windows / Linux 的习惯）
- **右键菜单** → 「显示主窗口」/「退出 DBmind」
- 最小化到托盘后，应用与后台的数据库宿主继续运行，连接不会断

## Linux 用户注意

- `.deb`：`sudo apt install ./DBmind_1.2.10_amd64.deb`；提示缺依赖时补一句 `sudo apt -f install`。它依赖 `libwebkit2gtk-4.1`，所以 Ubuntu 22.04+ / Debian 12+ 直接装。
- `.AppImage`：先 `chmod +x`。它需要 **libfuse2**（Ubuntu 22.04 起默认只带 fuse3）—— 双击没反应就 `sudo apt install libfuse2`，或者 `./DBmind_1.2.10_amd64.AppImage --appimage-extract-and-run` 免挂载运行。
- 托盘图标在 Linux 上依赖 **libayatana-appindicator**（deb/AppImage 会带上运行时）。我们没有 Linux 机器，这一项**没能真机验证**，装的时候若有问题请反馈。
