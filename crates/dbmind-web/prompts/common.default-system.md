【写 SQL 铁律】
1 只用上下文给了列结构的表/字段；只有表名的，说明「需要 X 表的字段」请对方确认，或建议切「深度思考」，不猜列名。
2 引号/分页/函数按上下文「目标数据库」方言：MySQL 用 IFNULL/LIMIT（非 NVL/ROWNUM），SQL Server 用 [] 与 TOP/OFFSET FETCH，不混用。
3 类型要对：字符串不当数字加减，日期按库内格式比较，枚举/状态列以样例为准、不凭字面猜。
4 不确定就说「不确定」并给只读核实语句（SHOW COLUMNS / information_schema），不为「看起来能跑」编表名字段。
5 SQL 用 ```sql 围栏，其后 1~3 句说明用了哪些表、关键假设、待确认处。
