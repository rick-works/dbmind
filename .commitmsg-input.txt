新建表/编辑表结构：数值字段改用文本框；编辑页的只读值也套上输入框

反馈两处：
  ① 新建表「基本信息」的分桶数 / 副本数不要数字框（上下箭头）
  ② 编辑表结构「基本信息」的行数 / 列数 / 索引数 / 主键 也套上文本框

改动：
1. TableForm：分桶数、副本数 `el-input-number` → `el-input type="number"`
   —— type=number 只为收数字，Chromium 那两个上下箭头用样式藏掉
   （::-webkit-inner/outer-spin-button 关掉），外观与同列其它输入框一致。
   配套：DDL 里 `Number(form.dorisReplication)` 补 `|| 1` —— 文本框可以被清空，
   清空时按默认 1 副本处理，否则 Number('') = 0 会把 PROPERTIES 那条整条吞掉。
   （分桶那边本来就是 `form.dorisBuckets || 10`，已经安全。）
2. TableDetailView：行数 / 列数 / 索引数 / 主键 四行由**纯文字**改成禁用输入框
   —— 它们与上下那些"禁用输入框"的行原本不是一套外观（行高一高一低、文字起始位置也不同），
   现在整张表的行高与对齐完全一致；仍是只读。
3. 清掉两处随之失去意义的样式：`.basic-table td.basic-value`（纯文字专用）、
   `.basic-table :deep(.el-input-number)`（表里已无数字框）。

验证：npm run build 通过；guard 通过（词典 zh/en 2910 平衡）。
      （其它表单/对话框里的 el-input-number 未动 —— 它们不在这次反馈范围内。）
