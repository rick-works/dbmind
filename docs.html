DBmind 文档

给数据库装上「大脑」的 AI 数据库工作台 —— 从安装到高阶用法，这里讲清楚每一件事。

什么是 DBmind？

DBmind = Database + Mind：给数据库装上「大脑」的统一管理工作台。它把连接管理、SQL 编辑、数据表格、AI 助手、事务与安全护栏放进同一个客户端，开箱即用。

DBmind 不绑定某一种数据库：MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、Redis、MongoDB、达梦、人大金仓等 17+ 种数据源共用一套操作习惯 —— 学一次，到处用。

提示：一切数据都留在你自己的网络里，AI 调用只发送你显式选中的内容。

核心特性一览

⌨️ 智能 SQL 编辑器VS Code 同款内核：上下文补全、格式化、分块执行、执行历史。
🤖 AI 助手解释 / 优化 / 修错 / 诊断 / 问答，给出的 SQL 可先看执行计划再落地。
🛡️ 事务模式写语句不再自动提交：先改、自查、回滚或提交，安全闭环。
✏️ 结果集直接编辑双击改值、缓冲提交，快照守卫绝不改错行。
⚡ 千万级结果集虚拟滚动 + 服务端分页 + 18× 压缩，首屏 <1s。
📊 透视与导出框选即汇总、分组下钻；CSV / Excel / JSON / INSERT 导出。

下载与安装

前往 GitHub Releases 下载对应平台的安装包：

  • Windows：下载安装包，双击安装，开箱即用
  • macOS / Linux：按 Release 提供的对应架构包安装

无需注册账号，无需配置云端服务，安装完成即是一个完整的本地工作台。

创建第一个连接

  • 左侧树点「新建连接」，选择数据库类型，填入主机 / 端口 / 账号密码
  • 首次连接某类型数据库时会自动下载对应驱动（内网环境可在 设置 → 驱动镜像 换成内网仓库）
  • 连接可分组管理；生产库建议开启 PROD 标记，界面会有醒目的颜色提醒

执行第一条 SQL

双击连接打开查询窗口，写一条 SQL，按 Ctrl+Enter 执行（或点「执行」按钮）：

-- 光标在这条语句内时，Ctrl+Enter 只执行这一条
SELECT * FROM orders WHERE created_at > :dt;
  • 编辑器里有 :name 占位符时，执行前会弹窗填参（见 模板变量）
  • 多语句脚本会自动分块执行，每段独立计时

SQL 编辑器

  • 上下文补全：按光标位置提示表 / 列 / 关键字，库结构变更实时刷新
  • 分块执行：光标语句或选中片段单独跑；「执行全部」跑整篇脚本
  • 格式化：整篇或仅选中段，一键整理混乱 SQL
  • 语句导航：脚本分块高亮 + 逐段计时条，长脚本也条理清楚
  • 执行历史：本地保存最近执行的 SQL，下拉一键回填

AI 助手

AI 能力覆盖写 SQL 的全流程，每个动作都可以先验证再落地：

  • 解释：选中 SQL，让 AI 逐段讲清在做什么、影响哪些表
  • 优化：给出改写建议与索引建议，可先看执行计划对比
  • 修错：语句报错后一键让 AI 修复，结果直接回填编辑器
  • 诊断：对慢 SQL 做性能诊断，定位瓶颈
  • 自由问答：AI 结合你的库结构回答，给出的答案可执行
安全边界：AI 给出的 SQL 会先「看执行计划、试跑一次」再让你决定是否执行 —— 不确定的话先开着事务模式再跑。

结果表格与数据编辑

浏览

  • 虚拟滚动：百万行丝滑滚动不卡顿
  • 列宽自适应、单元格完整内容悬浮查看、行详情一键打开
  • 异步计数：总数后台统计，不阻塞数据回显，可随时取消

编辑

  • 双击单元格改值（或右键「编辑此单元格」），改动先记入缓冲
  • 底栏「N 处修改待提交」：确认后一次批量提交，WHERE 自动生成（优先主键，否则全列定位）
  • 快照守卫：翻页 / 重跑后过期缓冲自动作废，绝不改错行
  • JOIN 查询会请你选择更新的目标表，工具不瞎猜列归属

事务模式

面向生产环境的安全编辑闭环：

  • 工具栏点「事务」开启：本会话所有写语句不再自动提交
  • 事务内的修改自己随时可查，其他会话看不到 —— 先改、先自查
  • 满意点「提交」落地；不满意点「回滚」全部消失
  • 有未提交事务时关页签 / 关窗口会弹窗确认，防止误关丢改动
  • 支持全部走 JDBC 链路的数据库（MySQL / PG / Oracle / ClickHouse / 达梦…）

对象浏览器

  • 左侧树按「连接 → 数据库 → Schema → 表 / 视图」展开
  • 表结构、索引、DDL 一键查看；双击表名插入编辑器
  • 连接分组管理，生产库 PROD 标记醒目外显

模板变量

把重复查询变成填空题：SQL 里写 :name 占位符，执行前弹窗填参。

SELECT * FROM orders
WHERE dt = :dt AND org = :org;
  • 字符串字面量里的冒号不误判（'12:30' 安全）
  • 数字直写、null 置 NULL、其余按字符串转义
  • 参数值按名称记忆（本地保存），下次自动带上

SQL 片段库

  • 选中 SQL → 工具栏「片段 → 存为片段」，命名保存（未选中存全文）
  • 跨会话保留在本地
  • 点击片段插入编辑器：有选区替换选区，否则插到光标处

数据透视

  • 结果表格里框选区域 → 一键汇总：计数 / 求和 / 均值 / 最值
  • 按列分组透视、下钻查看明细
  • 纯前端计算，不消耗数据库资源

导出与传输

  • 导出格式：CSV / Excel / JSON / INSERT 语句
  • 长任务后台跑：大数据量导出不占界面，完成后系统通知
  • 结构 / 数据传输：跨库搬表，字段映射可视化
  • 结构 / 数据对比：两库差异一键比对

安全护栏

  • PROD 标记：生产连接显式标识，误操作前多看一眼
  • 写操作确认：UPDATE / DELETE 执行前二次确认
  • 超时与行数预算：可配置单查询最大执行时间与返回行数
  • 数据本地化：连接配置与执行记录都在本机，不经过任何云端

驱动管理

  • 首次连接自动从 Maven 下载对应 JDBC 驱动并缓存
  • 内网环境：设置 → 驱动镜像，切换到内网仓库地址
  • 驱动版本与服务器不匹配时可手动安装指定版本

执行审计

  • 每条执行过的语句自动留痕：语句、目标库、耗时、成功与否
  • 事务的开启 / 提交 / 回滚同样留痕，可追溯

常见问题

连接提示「驱动宿主未就绪」？

驱动宿主需要 Java 17+。DBmind 启动脚本会自动探测本机 JDK 并固定；也可设置 DBMIND_JAVA 环境变量指向 Java 17+ 的 java.exe。

内网无法下载驱动？

设置 → 驱动镜像，换成公司内网的 Maven 仓库地址；或手动把驱动 jar 放入数据目录的 drivers/ 下。

事务按钮不显示？

会话级事务需要数据库支持（走 JDBC 链路的数据源都支持）；SQLite 等嵌入式引擎没有会话级事务，按钮自动隐藏。

结果集编辑提交报「缓冲已失效」？

翻页 / 重跑 / 重新排序后行号基准变了，旧缓冲会被快照守卫拦下 —— 重新双击编辑即可，这是防改错行的保护机制。
