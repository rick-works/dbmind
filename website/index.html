v1.2.20 修订版 2026-10-13
  • 「编辑表结构」在非默认模式下看不到字段的问题修好了 —— PostgreSQL / SQL Server / 人大金仓这类带「模式」的库，树上按「库.模式」取对象，但取"字段"那一路一直只认连接的默认模式（PG 是 public、SQL Server 是 dbo），于是别的模式下的表就成了「能列出表、字段却是空的」。现在整条链路（字段 / 建表语句 / 索引 / 注释 / 类型补全）都按你点的那个模式取
  • 取不到列不再静默给空：Doris 的元数据取不到时会以前如实返回「没有字段」，让人以为表坏了；现在明确报出原因（当前库不对 / 表不存在 / 没有 information_schema 读权限）
  • 大树不再卡：库里上千张表时，展开先出前 200 行、剩下的在后台自己长全（列表始终是完整平铺的，中间没有「显示更多」）；鼠标扫过连接节点也不再让整棵树重绘
  • 数据传输：修 MySQL 目标建表报 Row size too large (8126)（两处类型映射偏胖 + 显式 DYNAMIC 行格式 + 报错给出列规模）；写入侧并发与批事务调优，大表更快
  • 数据传输 → 选择对象：类型徽标改成筛选器 —— 点「表」只显示表、点「视图」只显示视图，再点一次回到全部；切类型时已勾选的对象不会再丢
  • 数据对比 / 数据传输：修「库不预选」；数据库右键菜单新增「数据对比」「数据传输」，并自动选中右击的那个库
  • 列类型写法统一：同一个类型「下拉里一种写法、回显另一种写法」的问题修掉了（MySQL 回 VARCHAR、Doris 回 STRING、PG 回 varchar…），按各库自身元数据的写法对齐
  • 新建表 / 编辑表结构：修打开「字段定义」报错；修列数超过 80 时点删除会删错行；类型格字号与同排其它列一致
  • 左侧树的右键菜单：点菜单里的按钮、或点其它任何地方，菜单都会关闭（以前会留在那儿挡操作）
  • SQL 编辑器：点结果页签自动选中对应的那条语句（与顶部语句页签一致）；语句面包屑与定位改以编辑器自身文本为准（修注释掉首条后编号与结果错位、点结果跳错语句）
  • 连接悬浮信息卡：不再挡住列表与点击，竖直居中、带指向连接的小箭头、字号与其它处一致
  • 分组可以置顶：分组右键新增「置顶分组」，顺序随设置保存
  • 设置：界面尺寸新增多项（首页卡片 / 弹窗标题与正文 / 数据视图表格 / 消息提示 / TAB 栏文字），SQL 格式化页与界面尺寸页的排布重排
  • 一批稳定性修复：设置页每次打开都会因一个不存在的函数中断后续加载（驱动列表 / 通知 / 知识库 / 快捷键因此是空的）、词典缺键与重复键、定时器在页面重挂后叠加、切表时字段可能串到另一张表、可增删列表的行状态串位、后台读取协程异常时不再误报「成功」

什么是 DBmind？

DBmind = Database + Mind：给数据库装上「大脑」的统一管理工作台。它把连接管理、SQL 编辑、数据表格、AI 助手、事务与安全护栏放进同一个客户端，开箱即用。

DBmind 不绑定某一种数据库：MySQL、PostgreSQL、Oracle、SQL Server、ClickHouse、Redis、MongoDB、达梦、人大金仓等 17+ 种数据源共用一套操作习惯 —— 学一次，到处用。

提示：一切数据都留在你自己的网络里，AI 调用只发送你显式选中的内容。

核心特性一览

⌨️ 智能 SQL 编辑器VS Code 同款内核：上下文补全、格式化、分块执行、执行历史。
🤖 AI 助手解释 / 优化 / 修错 / 诊断 / 问答，给出的 SQL 可先看执行计划再落地。
🛡️ 事务模式写语句不再自动提交：先改、自查、回滚或提交，安全闭环。
✏️ 结果集直接编辑双击改值、缓冲提交，快照守卫绝不改错行。
⚡ 千万级结果集虚拟滚动 + 服务端分页 + 18× 压缩，首屏 <1s。
📊 透视与导出框选即汇总、分组下钻；CSV / Excel / JSON / INSERT 导出。

下载与安装

前往 GitHub Releases 下载对应平台的安装包（Windows / macOS / Linux），双击安装，开箱即用。

  • 无需注册账号，无需配置云端服务
  • 首次连接某类型数据库时会自动下载对应驱动

创建第一个连接

  • 左侧树点「新建连接」，选择数据库类型，填入主机 / 端口 / 账号密码
  • 内网环境可在 设置 → 驱动镜像 换成内网仓库地址
  • 连接可分组管理；生产库建议开启 PROD 标记，界面有醒目颜色提醒

执行第一条 SQL

-- 光标在这条语句内时，Ctrl+Enter 只执行这一条
SELECT * FROM orders WHERE created_at > :dt;
  • 语句里有 :name 占位符时，执行前弹窗填参（见模板变量）
  • 多语句脚本自动分块执行，每段独立计时

SQL 编辑器

  • 上下文补全：按光标位置提示表 / 列 / 关键字，库结构变更实时刷新
  • 分块执行：光标语句或选中片段单独跑；「执行全部」跑整篇脚本
  • 格式化：整篇或仅选中段，一键整理混乱 SQL
  • 执行历史：本地保存最近执行的 SQL，下拉一键回填

AI 助手

  • 解释：选中 SQL，让 AI 逐段讲清在做什么、影响哪些表
  • 优化：给出改写建议与索引建议，可先看执行计划对比
  • 修错：语句报错后一键让 AI 修复，结果直接回填编辑器
  • 诊断 / 问答：性能定位与自由对话，AI 结合库结构给出可执行答案
安全边界：AI 给出的 SQL 会先「看执行计划、试跑一次」再由你决定是否执行。

结果表格与数据编辑

  • 虚拟滚动：百万行丝滑滚动不卡顿；单元格完整内容悬浮查看
  • 双击改值：改动先记入缓冲，底栏汇总后一次批量提交
  • 快照守卫：翻页 / 重跑后过期缓冲自动作废，绝不改错行
  • JOIN 支持：关联查询请你选择目标表，工具不瞎猜列归属

事务模式

  • 工具栏点「事务」开启：本会话所有写语句不再自动提交
  • 事务内修改自己随时可查，其他会话看不到 —— 先改、先自查
  • 满意「提交」落地；不满意「回滚」全部消失，全程留痕
  • 有未提交事务时关页签 / 关窗口弹窗确认，防止误关丢改动

对象浏览器

  • 左侧树按「连接 → 数据库 → Schema → 表 / 视图」展开
  • 表结构、索引、DDL 一键查看；双击表名插入编辑器

模板变量

把重复查询变成填空题：SQL 里写 :name 占位符，执行前弹窗填参。

SELECT * FROM orders
WHERE dt = :dt AND org = :org;
  • 字符串字面量里的冒号不误判（'12:30' 安全）
  • 数字直写、null 置 NULL、其余按字符串转义
  • 参数值按名称记忆（本地保存），下次自动带上

SQL 片段库

  • 选中 SQL → 工具栏「片段 → 存为片段」，命名保存（未选中存全文）
  • 跨会话保留在本地；点击插入：有选区替换选区，否则插到光标处

数据透视

  • 结果表格里框选区域 → 一键汇总：计数 / 求和 / 均值 / 最值
  • 按列分组透视、下钻查看明细；纯前端计算不耗数据库资源

导出与传输

  • 导出格式：CSV / Excel / JSON / INSERT 语句
  • 长任务后台跑：大数据量导出不占界面，完成系统通知
  • 结构 / 数据传输与对比：跨库搬表、差异比对

安全护栏

  • PROD 标记：生产连接显式标识，误操作前多看一眼
  • 写操作确认：UPDATE / DELETE 执行前二次确认
  • 超时与行数预算：可配置单查询最大执行时间与返回行数

驱动管理

  • 首次连接自动从 Maven 下载对应 JDBC 驱动并缓存
  • 内网环境切换镜像地址，或手动放入驱动 jar

执行审计

  • 每条执行过的语句自动留痕：语句、目标库、耗时、成功与否
  • 事务的开启 / 提交 / 回滚同样留痕，可追溯

常见问题

  • 「驱动宿主未就绪」？宿主需要 Java 17+，启动脚本会自动探测并固定；也可设 DBMIND_JAVA 指向 Java 17+
  • 内网无法下载驱动？切换驱动镜像到内网仓库，或手动放入数据目录的 drivers/
  • 事务按钮不显示？SQLite 等嵌入式引擎没有会话级事务，按钮自动隐藏
  • 编辑提交报「缓冲已失效」？翻页 / 重跑后行号基准变了，重新双击编辑即可 —— 这是防改错行的保护
